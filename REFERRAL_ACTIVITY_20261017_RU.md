# TERRITORY — «Друзья»: 5-й уровень и 10 побед в первой игровой сессии

## Новое правило
Приглашённый Telegram-игрок засчитывается за 5-й уровень персонажа и как минимум 10 засчитанных сервером побед в походах или испытаниях. **Ожидание 24 часов отменено**. Если игрок дойдёт до цели через час, день или неделю — награда будет доступна после выполнения цели. 45 минут — ориентир игрового опыта, НЕ таймер допуска.

Накопленные награды сохранены: 0,2 красного алмаза за каждого квалифицированного друга (5 целочисленных осколков = 1 целый), один навсегда запечатанный сундук, 1500 золота/10 синих алмазов/2 материала кузницы/боевые камни за первых десять, разовые награды за пороги 3 и 5 друзей. Лимит на покупку 25 камней в сутки не меняется.

## Где друзья
После подтверждённого Telegram-входа в разделе «Друзья» ниже приглашения появляется компактный список «Мои друзья»: имя героя, уровень/5, учтённые победы/10, в процессе или засчитан. Сначала видны 5 карточек, остальные по кнопке. Не раскрываются ID Telegram, email, инвентари и персональные аккаунты. Когда приглашённых нет, видна понятная пустая секция.

## Серверный прогресс и ограничения безопасности
Только подписанная Telegram-пригласительная ссылка может установить пригласившего. Сервер хранит приватный прогресс игрока, в браузер выдаёт только свой однократный билет на конкретный PvE бой. При победе уходит список реально нажатых атак/блоков; сервер проверяет вид противника, форму хода, однократность билета, невозможную быструю накрутку и 3+ раунда для боссов/испытаний согласно ограничению урона.
По билету начисляется серверная проверочная величина XP, не принимающая произвольные значения из браузера. Для реферальной квалификации одновременно нужны 10 таких завершённых попыток, накопленная серверная XP по консервативному правилу и сохранённый пятый уровень. После задержки облачного сохранения статус пересчитывается при открытии страницы друзей. Отдельная серверная таблица сундуков и атомарная выдача наград остаются прежними.

**Не путать с полностью серверно-авторитетным PvE:** фактический исход обычного PvE пока рассчитывает браузер. Серверный билет, тайминг и проверка ходов защищают от тривиальной записи уровня/побед в сохранение, но продвинутый злоумышленник всё ещё может эмулировать клиентские запросы. Для защиты всех игровых наград необходим полный перенос симуляции PvE на сервер. Этот риск отдельно учитываем до платного запуска.

## Публикация
1. Дождаться зелёного CI для PR №28, включая `npm run test:referral-activity` и `npm run test:founders`, PVE/economy/build.
2. Применить новую миграцию `supabase/migrations/20261017_referral_activity_level5_10wins_v2.sql` в существующий Supabase.
3. Убедиться, что аккаунты, старые награды и подтверждённые основатели не потерялись; закрытые таблицы защищены.
4. Слить PR и дождаться обеих успешных публикаций GitHub Pages.
