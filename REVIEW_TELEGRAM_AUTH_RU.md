## Изменения

- Перенесены auth.ts и два точечных патча App/Profile из Territory_SAFE_AUTO_REVIEW_SETUP.zip. Патчи применились без конфликтов.
- Вход использует UUID подтверждённой Supabase-сессии. Ошибка Telegram не открывает кешированный чужой аккаунт. Самостоятельное создание гостя убрано с экрана приветствия.
- Старый авторизованный гость привязывается с сохранением UUID. При ошибке привязки вход останавливается; только явный конфликт уже привязанного Telegram допускает вход в его подтверждённый аккаунт.
- Исправлен дополнительный риск архива: сервер больше не переиспользует auth-пользователя по совпадению синтетического email и не делает upsert существующего героя. Ошибки поиска останавливают вход. UUID выдаваемой сессии проверяется.
- Привязка выполняется условным обновлением только непривязанной записи и сохраняет существующий email auth-пользователя. Никаких удалений auth.users или персонажей. Конфликт требует отдельного восстановления владения.
- Edge Functions в этой ветке — только исходники. Ничего не отправлено в Supabase.
- review-ci.yml автоматически запускает TypeScript, Vite, проверки баланса, профессий, разделения экранов, мобильного UI и offline-тесты авторизации. Права CI только contents:read, без production-секретов и без публикации.
- В копиях трёх рабочих workflows добавлены ограничения main. Автораспаковка дополнительно фильтрует push по main. Эти правки действуют только в review-ветке; main не изменён.
