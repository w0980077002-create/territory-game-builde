# Sharing, referrals and anti-spam policy (2026-10-19)

Monopoly > Quests contains a daily Telegram bonus: **2 tickets once every 24 hours for opening the share recipient picker**. The button uses the player's verified personal bot deep link. Telegram cannot prove sending or delivery, so the game does not claim either is verified. No new player or referral qualification is required for this daily bonus; nothing is sent automatically. The existing server cooldown and ticket ceiling remain unchanged.

Qualified referrals are a separate feature in Friends: level 5 and 10 server-recorded PvE wins. That reward ledger is independent of the daily sharing bonus. Cancelling the Telegram picker does not undo the opening bonus; this is stated to the player before pressing the button.

The battle chat refuses referral / URL spam in the server-side arena_chat RPC (and shows an explanation), without silently muting/banning players. This does not moderate the independently hosted Telegram group https://t.me/Territory_Chat — that would require separate bot admin permissions and a Telegram group-moderation workflow. No group's Telegram message is deleted by this change.
