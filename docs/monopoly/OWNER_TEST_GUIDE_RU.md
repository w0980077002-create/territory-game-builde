# Закрытый тест Монополии: инструкция владельцу

Изменения находятся в ветке `review/monopoly-safe-test-20261017`. Pull Request — предложение изменений для проверки. **Не нажимайте Merge и не запускайте публикацию main**, пока тест не завершён.

## Что уже готово

- Новый экран, анимированные броски и движение, круги, события, задания и награды.
- Настоящий кошелёк билетов игрового зала; золото поступает в награды зала и забирается существующей кнопкой. В тестовой копии это будут тестовые балансы, изолированные от рабочей игры.
- Добавлены настоящие синие алмазы, боевые камни, материалы кузницы, зелья здоровья и эликсиры силы. Они копятся до получения кнопкой под полем; после получения игра автоматически обновляется. Существующие предметы и красные алмазы сохраняются.
- SQL проверен локально. Рабочую базу проверяли только чтением структуры, без установки и изменения данных.
- Серверный список приглашённых: после установки он пуст; ссылку недостаточно переслать, чтобы получить доступ к Монополии.

## Как получить закрытый тест на Android

Нужно один раз подготовить тестовую копию. Передайте техническому помощнику файл `INSTALL_AND_REVIEW_RU.md` из этой папки и попросите:

1. Создать **отдельный тестовый Supabase**, без сохранений настоящих игроков. Настроить там рабочую схему TERRITORY и отдельного тестового Telegram-бота. Рабочего бота не переключать.
2. Установить только проверенный SQL `supabase/staged/territory_monopoly_v2.sql` в тестовую базу. Зайти через тестового бота один раз, затем добавить ваш тестовый аккаунт в список приглашённых. Рабочую базу пока не трогать.
3. Добавить в GitHub Environment `monopoly-test` две настройки тестового проекта: `MONOPOLY_TEST_SUPABASE_URL` и `MONOPOLY_TEST_SUPABASE_ANON_KEY`.
4. Открыть GitHub → Actions → **Monopoly - isolated review and test artifact (no deployment)** → Run workflow → выбрать ветку `review/monopoly-safe-test-20261017`. Если новая процедура ещё не показывается в списке, помощник запускает её через GitHub CLI для этой ветки или собирает архив локально — инструкция есть в техническом файле. Объединять PR ради кнопки не нужно.
5. Скачать архив `monopoly-android-test-…` из завершённой процедуры. Помощник размещает его на **отдельном тестовом HTTPS-сайте**, не на адресе рабочей TERRITORY, и указывает этот адрес как Mini App URL отдельного тестового бота. Сама процедура ничего не публикует.
6. На Android откройте тестового бота в Telegram, нажмите кнопку открытия игры и перейдите **Игры → Монополия**. В обычном браузере Telegram-авторизация может не сработать — открывайте именно через кнопку Mini App, а не как обычную ссылку.

Тестовый сайт и бот пока не созданы и не опубликованы. Готовы код, проверка сборки и порядок запуска; потребуется отдельный тестовый проект и его настройки.

## Что проверить на телефоне

- До и после броска: обычный ход списывает 1 билет, ×10 — 10. Частые нажатия во время хода не создают второй ход.
- После закрытия Mini App незавершённый ход можно продолжить без ещё одного списания.
- Награда не начисляется повторно при обновлении окна и повторном нажатии. Золото забирается в игровом зале ровно один раз.
- В заданиях видно настоящий прогресс; полученная награда меняет состояние на «Получено».
- Окна подарков, предложений, круговых наград закрываются; экран не обрезается, кнопки доступны при небольшой высоте.
- Удвоение, выбор кубика, телепорт и сокровище работают. Для редких событий помощник использует только тестовую базу, не рабочую.
- Попробуйте плохой интернет, перезапуск Telegram, режим ×10, отсутствие билетов, два устройства/окна одного тестового аккаунта и аккаунт без приглашения.
- Сравните инвентарь, алмазы и материалы до/после. Откройте остальные игры и проверьте скрытый вход пятью нажатиями в прежнем месте.

## Перед рабочей установкой

После успешного теста технический помощник должен показать результаты, резервную копию и план возврата. Только после вашего отдельного подтверждения можно обсуждать установку SQL в рабочую базу. Для общей публикации также потребуется отдельное решение: текущий SQL намеренно оставляет серверный список приглашённых.

Браузерная проверка здесь не выполнена из-за ограничений окружения. Android/Telegram и работа с реальной авторизацией тестового проекта ещё не проверены. Автотесты не заменяют эти пункты.
