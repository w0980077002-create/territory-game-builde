# TERRITORY 1.0 — единый боевой пакет (28.10.2026)

**Статус:** изолированная лаборатория в черновом PR #96, не включена в боевую версию игроков. Точка входа: `#idle-preview`. Ни Supabase, ни сохранения и награды существующих игроков не изменяются. TERRITORY 2.0 не затрагивается.

## Реализовано одним пакетом

- **Бои.** Детерминированная модель ударов, честные двойные/тройные комбинации с разными контактами, уклонение, блок, крит, накопление энергии, 15 активных навыков (5 веток), 6 рун в двух гнёздах каждого выбранного навыка и 3 пассивных навыка. Защитные и атакующие эффекты рассчитываются на уровне движка; визуализация не снимает HP второй раз.
- **Приключение.** Пять глав по 20 этапов (100 всего), пять видов обычных врагов, элита на 5-м и 15-м этапах каждой главы, боссы на 10-м и 20-м. Десять настоящих оригинальных боссов и их индивидуальные способности; рост характеристик врага по номеру этапа. Карта этапов, открытие следующих этапов и демонстрационный опыт действуют только в открытой вкладке.
- **Персонажи.** Четыре утверждённых облика героев с общим интерфейсом экипировки. Пять утверждённых спутников со своими оригинальными спрайтами и независимыми интервалами действий; физические удары, магия, лечение и защитные эффекты действительно влияют на результат симуляции.
- **Добыча.** Разлёт визуальных предметов после победы, обычная/редкая/эпическая/легендарная редкость, автоматическое занятие свободных ячеек, временная сумка, сравнение и переодевание. Пока это демонстрационные предметы без записи на сервер и без влияния характеристик на боевые расчёты.
- **Мобильная работа.** Предзагрузка нужных поз героев, спутников, текущего и следующего противника, пауза расчёта в фоновой вкладке, ограниченная частота обновления интерфейса, компактные боевые эффекты и адаптивный экран.

## Использованные иллюстрации

В `public/assets/territory/characters` уже есть шесть поз (`idle`, `attack`, `hit`, `block`, `dodge`, `death`) для четырёх героев, пяти врагов, пяти спутников и десяти боссов. Используем существующие утверждённые файлы, не заменяем их процедурно нарисованными силуэтами или перекрашенными гоблинами. Создание новых платных ресурсов не требуется.

## Проверки

```bash
npm run typecheck
npm run build
npm run test:idle-engine
node scripts/check-idle-content.mjs
npx eslint src/components/idlePreview/IdleCombatPreview.tsx src/game/idleContent src/game/idleEngine
```

Проверки содержат детерминизм боевых событий, HP-учёт ударов/лечения, действительные действия спутников, способности боссов, последовательность всех 100 этапов, существование одобренных ассетов, экипировку и качество каталога. Это автоматические проверки, а не полноценная ручная проверка в Telegram/iPhone/Samsung.

## Границы безопасного внедрения

1. Провести визуальное тестирование лаборатории на Android и iPhone, включая реально длинные бои с пятью спутниками и боссами.
2. Привязать обновлённый движок к действующим данным героя и статам экипировки, не меняя проверенные механизмы начисления статов/админку.
3. Отдельно определить и подключить **серверные** награды, сохранение этапов и получение опыта с защитой от повторного начисления. Сейчас предметы, опыт и открытия этапов живут исключительно в оперативной памяти вкладки.
4. Только после тестов интеграции отдельно согласовать включение живым игрокам, чтобы не ломать Арену и текущий игровой прогресс.

Не объявлять лабораторные визуальные эффекты выдачей предметов игроку или рабочей серверной экономикой.
