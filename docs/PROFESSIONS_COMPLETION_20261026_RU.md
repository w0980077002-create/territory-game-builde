# Профессии: проверенный пакет 26.10.2026

Исправлены потеря UUID незавершённого ремесла/покупки при перезапуске Telegram, смешивание операций разных аккаунтов, повторное нажатие до перерисовки интерфейса и зависшая сверка расходника, чей семидневный срок уже истёк. Старые сохранённые UUID переносятся из вкладки в постоянное хранилище. Ошибка хранилища останавливает новую операцию до списания. Тексты резервного экрана теперь соответствуют существующей лицензии за 50 красных алмазов в магазине.

Проверки: `npm run test:professions`, `npm run test:professions:stage8`, `npm run test:master-license`, `npm run typecheck`, `npm run build`. Добыча по четыре часа, постоянное хранение добытых ресурсов, семидневные расходники, характеристики рецептов и утверждённые изображения сохранены.

## Продолжительность развития

Воспроизводимый расчёт для всех пяти профессий: `node scripts/professions/progression-report.mjs`. Все ресурсы направляются в обучение; изготовление вещей и пропущенные дни увеличивают срок.

| Добыч в сутки | Существующая модель до 300 | Предложение: половина XP на уровень |
|---|---:|---:|
| 2 | 483–484 суток | 243 суток |
| 3 | 322 суток | 162 суток |
| 4 | 310 суток | 155–156 суток |
| 6 | 297 суток | 149 суток |

Существующая модель требует 73 199 XP. Предлагаемый вариант требует 36 662 XP, сохраняет награды за тренировку, её цену в ресурсах, характеристики/стоимость вещей и лимит 300 XP/сутки. Это ускорение примерно с 11 до 5,5 месяцев при трёх добычах/сутки, без сокращения четырёхчасовой добычи. Предложение не включено в игру: старые уровни и доли XP необходимо сохранить при отдельном проверяемом переходе.

Администраторские выдачи ресурсов и отдельный временный owner test access исключаются из этих оценок. Последний намеренно позволяет проверить цепочку 1–300 за одну сессию; это не поведение обычного игрока.

## Оставшаяся граница

Полная серверная экипировка/расходование предметов и совместимый переход старых сохранений остаются зависимостями выпуска Stage8. Локальная копия серверной вещи для отображения не доказывает серверную проверку её использования. Этот пакет не включает флаги производства и не объявляет профессии полностью завершёнными.
