# Задача: [название одной строкой]

## Что игрок увидит
Пошагово, как в игре:
1. Открыть [экран] через [путь в меню, например: Город → VIP (прямое нажатие на VIP)].
2. Видно: [элементы, тексты, состояния, какой стиль].
3. По нажатию: [что происходит; если это заглушка — так и написать].

## Этап и предварительная сверка существующего
- **Сначала проверить main и live-статус:** что уже существует в интерфейсе, сохранениях, серверных RPC и реальной игре; не создавать дубль, не заменять живые данные заглушками.
- **Если функция действительно новая:** первый безопасный этап — рабочий видимый прототип с оригинальными изображениями и понятным действием. Не выдавать локальную имитацию за реальную механику.
- **Если функция уже имеет серверную часть:** исправить конкретную недостающую связь (экран → действие → сохранение → эффект), не откатывая серверную реализацию ради нового макета.
- **Новые изменения production Supabase, денежных списаний, реальных наград, экономического баланса и опасных миграций** — только с отдельным разрешением владельца и адресной проверкой (AGENTS.md, раздел 2). Уже работающие защищённые механики сохранять.

## Критерий готовности
- [ ] Экран открывается по указанному пути.
- [ ] Все элементы из раздела «Что игрок увидит» на месте.
- [ ] Стиль соответствует эталонам (Лавка, Арена) по docs/ART_STYLE_LOCKED_TERRITORY_V1_20261027_RU.md.
- [ ] Мобильная ширина 360 px не ломает вёрстку.
- [ ] `npm run typecheck` и `npm run build` проходят.
- [ ] Изменение попало в `main`, публикация GitHub Pages успешна, результат виден в игре.

## Что НЕ делать
- Серверную часть и реальные списания/начисления без отдельного разрешения.
- Баланс, цены и награды сверх указанных в ТЗ.
- Менять разделы, которые не указаны в ТЗ.
- Заменять утверждённый арт (список в AGENTS.md, раздел 6).

## Данные
Какие значения взяты из действующего каталога/серверного статуса. Если демонстрационные данные нужны для теста — явно пометить их и изолировать от реальной игры; не выдумывать уровни, силу, проценты, балансы, награды или доступ к уже принадлежащим игроку предметам.
