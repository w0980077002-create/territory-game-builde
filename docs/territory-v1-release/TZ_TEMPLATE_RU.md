Используется для любой новой игровой задачи. Правила работы — в [AGENTS.md](../../AGENTS.md). Этот шаблон описывает, **что игрок должен увидеть**, а не внутреннюю систему.

---

# Задача: [название одной строкой]

## Что игрок увидит
Пошагово, как в игре:
1. Открыть [экран] через [путь в меню, например: Город → Лавка → вкладка VIP].
2. Видно: [элементы, тексты, состояния, какой стиль].
3. По нажатию: [что происходит; если это заглушка — так и написать].

## Этап
- **Этап 1 — видимый клиент:** экраны, вкладки, кнопки, заглушки и локальные данные. Делается сразу.
- **Этап 2 — сервер, защита, валидация, реальные награды:** только после отдельного письменного разрешения владельца (см. AGENTS.md, раздел 2).

## Критерий готовности
- [ ] Экран открывается по указанному пути.
- [ ] Все элементы из раздела «Что игрок увидит» на месте.
- [ ] Стиль соответствует эталонам (Лавка, Арена) по docs/ART_STYLE_LOCKED_TERRITORY_V1_20261027_RU.md.
- [ ] Мобильная ширина 360 px не ломает вёрстку.
- [ ] `npm run typecheck` и `npm run build` проходят.
- [ ] Изменение попало в `main`, публикация GitHub Pages успешна, результат виден в игре.

## Что НЕ делать
- Серверную часть и реальные списания/начисления без отдельного разрешения.
- Баланс, цены и награды сверх указанных в ТЗ.
- Менять разделы, которые не указаны в ТЗ.
- Заменять утверждённый арт (список в AGENTS.md, раздел 6).

Что захардкодить на этапе 1 (значения-заглушки, без сохранения).
