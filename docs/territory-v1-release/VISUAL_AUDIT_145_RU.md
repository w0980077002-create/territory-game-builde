# Редизайн #145: маршруты и проверка

Черновик PR #146. Применение общего класса не означает визуальной приёмки экрана. Все проверки ниже — локальный Chromium с тестовыми данными; не реальный Telegram и не производственные игроки.

Примеры до/после текущего прохода на 360×500: [предмет до](visual-145/item-before-360.png), [предмет после](visual-145/item-after-360.png), [профиль до](visual-145/profile-before-360.png), [профиль после](visual-145/profile-after-360.png). «До» — состояние коммита `3ffc0d8`, а не исходный main; фикстура подменяет зависимости. Это не полный набор доказательств для #145.

Для приёмки остаются сравнения до/после, реальные маршруты и вложенные состояния на четырёх ширинах и в двух языках, доступность всех окон, итоговый CI и проверка фактического Telegram WebView при наличии устройств. Выкладка и изменение данных игроков не выполнялись.
