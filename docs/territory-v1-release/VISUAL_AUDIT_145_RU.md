## Реализация в текущем PR после a45ce60 (не означает визуальную приёмку)

- 11 живых маршрутов (магазин, обычные и Stage8-профессии, кузница, задания, друзья, клан, аукцион, рейтинг, сезон, события) получили **отдельно ограниченный** `viking-screen` и единый `vikingScreenSkin.css`. Это не глобальная перекраска игровых сцен и не вмешательство в RLS или прогресс.
- Деревянные кнопки/вкладки с реальным состоянием `aria-selected` есть в магазине, профессиях, аукционе и переключателе Поход/Испытания/Тёмная пещера. Письма получили те же вкладки.
- Лагерь спутников, дополнительные панели, события и окна при изменении экипировки стилизованы без изменения картинок героев, рунических эффектов или серверного расчёта.
- Локальные диалоги: окно ухода с Арены (alertdialog, Escape, возврат фокуса), кузница (обозначение dialog, крестик 44px, ограничение размера и scroll), выбор рун, колесо (правила/награды), информационные панели Монополии. В колесе оставлено исходное подтверждение OK, не меняющее сценарий выдачи.
- В безопасный PR CI добавлен `npm run test:visual-viking`, который статически проверяет **структуру** этих мест и заданные ограничения. Этот тест **не** заменяет браузерное сравнение и проверку реального Telegram.

### Что по-прежнему НЕ доказано

- Все 11 маршрутов и независимые состояния Арены/PvE/карты ещё не проверены с настоящим Telegram WebView, реальными вложенными окнами и RU/EN на физических устройствах.
- Полный набор визуальных скриншотов из исходного `main` и текущего PR пока отсутствует; приложенные ранее примеры происходят из изолированного стенда.
- Финальные GitHub Actions и проверка загрузки каждой графики должны завершиться на **последнем SHA** до выпуска. Внешний лимит Vercel не лечить платной подпиской.
- Отображение в реальной игре возможно только после проверки и объединения PR, а не после CSS-коммита.

Для приёмки остаются сравнения до/после, реальные маршруты и вложенные состояния на четырёх ширинах и в двух языках, доступность всех окон, итоговый CI и проверка фактического Telegram WebView при наличии устройств. Выкладка и изменение данных игроков не выполнялись.
