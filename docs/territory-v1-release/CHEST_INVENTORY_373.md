## Что уже сделано в этом PR
- Окно открытия в Казне: отдельные состояния закрыт / открывается / открыт.
- Изображение сундука имеет размер (раньше `<img>` не получал стилей, а свечение висело на несуществующем `span`).
- Свечение награды: обычное и золотое, сильнее в открытом состоянии.
- Отключено движение для `prefers-reduced-motion` (правило уже есть для `.fortune-dialog *`).

## Что не проверено
- Браузерные скриншоты 320/360/390/430 px генерирует `treasury-chest-visual.yml`; новая проверка включает открытие обычного и редкого на 360/390 px. Требуется зелёный CI на последнем SHA и приёмка владельцем.
- Другие сундуки explorer, guardian, legendary, слоты и VIP — отдельные задачи #373. Новые WebP относятся только к Казне.

Шансы, награды, валюты, Supabase, инвентарь, логика открытия.
