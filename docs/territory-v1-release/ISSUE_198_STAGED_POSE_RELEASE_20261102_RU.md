# TERRITORY — безопасный выпуск сценических анимаций из #205

**Решение владельца, 02.11.2026:** выпустить уже готовый и прошедший проверки блок движений без ожидания неподготовленных skeletal-артов.

## Что выпускаем
- Настоящие исходные `idle/attack/block/dodge/hit/death` позы без подмены внешности.
- Контакт и восстановление, x1/x2 и отмена устаревших событий; уже существующие male_viking/goblin skeletal rig не меняют арт-каталог.
- Безопасный same-character fallback для недоступных поз; на слабых телефонах отключены дополнительные FX; reduced-motion подпись урона появляется с контакта.
- Результат боя берётся из реального состояния / подтверждённых серверных квитанций; анимация сама не начисляет награды, не меняет HP, не совершает ход.
- При выпуске `main` проходит `test:combat:poses` в mobile-browser CI и обычные проверочные сценарии.
 
## Что НЕ выпускаем
- Неутверждённые риги и WebP-кандидаты кабана, разбойника или спутника из `docs/art-reference/issue198`.
- Обещание полной скелетной анимации героев, спутников и врагов: это остается **ART BLOCKED** и открыто в Issue #198 / draft PR #205.
- Никаких изменений кнопок, EXP, HP, энергии, зимнего фона, трёх позиций Города, игрового прогресса, Supabase/SQL/Edge, реальных денег и баланса.

**Граница тестов:** автономные React/Chromium в CI не эквивалентны проверке Telegram на физических Android/iPhone и сетевой арены. Это открытые ограничения, не выдавать за PASS.
