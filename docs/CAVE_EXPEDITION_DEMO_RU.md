# TERRITORY — Тёмная пещера DEMO, P0 #471

Вход в самой игре: **Поход → Тёмная пещера → Новая экспедиция · тест → Играть DEMO**. Во время забега сцена открывается поверх внешних вкладок и городской навигации. Кнопка назад открывает паузу; «К входному порталу» возвращает к существующим этажам. При незавершённой серверной попытке сохраняется прежний безопасный вход в её восстановление.

Это отдельный локальный тестовый забег. Нет списания камней, настоящих наград, обращения к игровому серверу или записи прогресса. Перезагрузка завершает DEMO. Состав фиксированный: одобренные викинг, Северный воин и Лесная целительница. Настоящие 100 этажей и награды остаются в «Мои этажи · награды».

## Что изменено

- Полноэкранная адаптивная сцена, компактные ресурсы и четыре действия, безопасные области; внешние элементы недоступны клавиатуре, пока открыт бой.
- Единая линия ступней: точки опоры рассчитаны из прозрачности каждого кадра заранее. Разведены спутники и дистанция босса; видны здоровье и действия спутников.
- Первая волна через 2,4 секунды бега, последующие через 1,2. Боковое движение и камера сохраняются во время сближения и зачистки. По пути можно коснуться искры, один раз за комнату получив 10 демонстрационной энергии.
- Исходные рисованные панорамы соединяются перехлёстом без отражений; отдельные планы скал, грунта, декораций и частиц. Споры, искры и звёзды различаются по биомам. Сохранены исходные покадровые run/attack/hit/death, добавлены мягкая остановка попадания, реакции и видимые снаряды спутников.
- «Авто навыков» управляет только способностями. Базовые удары автоматические. Раскол: 105 по группе, 32 энергии / 6 секунд; Заслон: −85% входящего урона на 2,1 секунды, 22 / 5 секунд; Источник: до 280 HP героя и 65 живых спутников, 35 / 12 секунд. Регенерация 1,8/с, за врага +3. Все коэффициенты изолированы от настоящего баланса.
- Две независимые развилки с видимыми арками и касанием самой арки. Герой входит в выбранную дверь, меняются биом и противники. Никаких обещаний реальной добычи.
- Собор: три фазы по HP, усиление и ускорение атак; обвал, разлом и дождь осколков с предупреждением перед ударом. Защита действительно уменьшает урон. Без навыков отряд проигрывает; осмысленное ручное управление и авто навыков проходят все маршруты.
- Победа/поражение с маршрутом, временем, числом врагов, блоков и навыков; два действия — повторить и выйти. Трофеи явно обозначены образцами без выдачи.
- Оригинальный синтезированный звук шагов, ударов, щита, лечения, портала и босса, тихий фон и выключатель. Звук запускается пользовательским жестом, останавливается при паузе/скрытии/выходе; AudioContext закрывается при размонтировании.
- RU/EN, reduced motion, пауза, помощь, поворот экрана, скрытие/возобновление, очистка RAF и слушателей; понятный повтор загрузки при недоступном арте.

## Проверки

`npm run typecheck`, `npm run build`, ESLint изменённых TS/TSX; `npm run test:cave-expedition`; существующие cave systems/belt/dark stones/adventure UI/receipts и проверки восстановления, победы и повторной загрузки PvE.

`npm run test:cave-expedition:browser`: четыре комбинации маршрутов на 320/360/390/430×720, настоящие touch-кнопки, ручное прохождение на 390, авто на остальных, обе развилки, победа/поражение, повтор, пауза, mute, hidden/resume/unmount, отсутствие прокрутки и внешних запросов. Дополнительно RU/EN, reduced motion, 320×568, 360×640, 640×360 и автономность после загрузки.

`node scripts/build-journey-preview.mjs && python scripts/check-journey-browser.py`: настоящий BattleScreen, поддельный транспорт без аккаунта; Поход/Испытания, вход/выход DEMO, сохранность хранилища, повторный вход и приоритет восстановления реальной попытки на четырёх ширинах в RU/EN.

`python scripts/check-cave-expedition-performance.py`: диагностический Chromium 360×640 с CPU 4×, кадры, память и длинное нажатие. Это **не измерение настоящего Android**. `python scripts/record-cave-expedition.py`: полная запись нового кода в реальном времени, без ускорения модели и искусственной победы. Видео и полный набор кадров доступны в артефакте существующей cave CI-проверки; ZIP для игры не требуется.

Кадры и отчёты P0: [бой](evidence/cave-p0-20261111/390-fight.png), [порталы](evidence/cave-p0-20261111/390-portals-1.png), [босс](evidence/cave-p0-20261111/390-boss.png), [победа](evidence/cave-p0-20261111/390-victory.png), [браузер](evidence/cave-p0-20261111/browser-report.json), [производительность](evidence/cave-p0-20261111/performance-report.json).

Настоящий Android, Telegram WebView, субъективное качество звука и итоговая UX-приёмка требуют проверки владельца на телефоне. Видео владельца `1000088524.mp4` в этой сессии не было доступно; использованы точные замечания из #471. Серверный multi-room, настоящее снаряжение и награды — отдельный P1, здесь не активируются.

## Воспроизведение разработчиком

```sh
npm run test:cave-expedition
npm run build:cave-preview
npm run test:cave-expedition:browser
python scripts/check-cave-expedition-performance.py
node scripts/build-journey-preview.mjs
python scripts/check-journey-browser.py
```

Сборщик использует тот же компонент, что игра; автономный HTML — технический smoke, не второй процесс публикации. Существующий Pages workflow публикует только проверенный main. Публичный SHA проверяется через `scripts/check-published-pages.mjs` после успешного deploy.
