# TERRITORY — Тёмная пещера DEMO, P0 #471

Вход в самой игре: **Поход → Тёмная пещера → Новая экспедиция · тест → Играть DEMO**. Во время забега сцена открывается поверх внешних вкладок и городской навигации. Кнопка назад открывает паузу; «К входному порталу» возвращает к существующим этажам. При незавершённой серверной попытке сохраняется прежний безопасный вход в её восстановление.

Это отдельный локальный тестовый забег. Нет списания камней, настоящих наград, обращения к игровому серверу или записи прогресса. Перезагрузка завершает DEMO. Состав фиксированный: одобренные викинг, Северный воин и Лесная целительница. Настоящие 100 этажей и награды остаются в «Мои этажи · награды».

## Изменения по скриншотам владельца — компактная комната и физический контакт

- Пять оригинальных портретных комнат вместо увеличенной панорамы. Широкий каменный пол, глубина, опоры и свет; убрана чёрная линия-платформа. Пропорции рисунков сохраняются. Старые одобренные персонажи и атласы не перезаписывались.
- Компактная шапка и панель четырёх умений, отдельный переключатель «Авто». Учитываются `--territory-viewport-height`, `--territory-top-inset` и `--territory-bottom-inset`, как у города: нативные кнопки Telegram не должны закрывать управление.
- Герой: существующие раздельные руки, предплечья, щит, меч, ноги и колени. Три замаха, контакт на 0,3 секунды, восстановление, защитная стойка, реакция и уклон. Суставы и эффекты следуют часам движка и замерзают на паузе.
- Спутники: масштаб по видимой фигуре без прозрачных полей, разная глубина и точки опоры. Воин делает выпад; целительница посылает снаряд. Урон наносится при контакте, а не при начале движения. Используются исходные позы, не заявляются новые полноценные суставные модели спутников.
- «Раскол»: 105 по группе после замаха, 32 энергии / 6 секунд. «Защита» (Заслон): −85% урона на 2,1 секунды, 22 / 5 секунд. «Лечение» (Источник): до 280 HP героя и 65 живых спутников, 35 / 12 секунд. «Уклон»: окно 0,65 секунды, 18 / 5 секунд; нажатие после попадания не отменяет полученный урон. Числа относятся только к DEMO.
- Вспышки контакта, искры, след клинка, лечение, блок и уклон привязаны к событиям; ударный звук совпадает с попаданием. Авто использует защиту и уклон как запасной вариант.
- Сохранены три комнаты, две независимые развилки, четыре маршрута, фазный босс, пауза/справка, звук, победа/поражение, повтор и RU/EN. Настоящие награды и новые 21 персонаж не импортированы.

## Проверки

`npm run typecheck`, `npm run build`, ESLint изменённых TS/TSX; `npm run test:cave-expedition`; существующие cave systems/belt/dark stones/adventure UI/receipts и проверки восстановления, победы и повторной загрузки PvE.

`npm run test:cave-expedition:browser`: четыре комбинации маршрутов на 320/360/390/430×720, настоящие touch-кнопки, ручное прохождение на 390, авто на остальных, обе развилки, победа/поражение, повтор, пауза, mute, hidden/resume/unmount, отсутствие прокрутки и внешних запросов. Дополнительно RU/EN, reduced motion, 320×568, 360×640, 640×360 и автономность после загрузки.

`node scripts/build-journey-preview.mjs && python scripts/check-journey-browser.py`: настоящий BattleScreen, поддельный транспорт без аккаунта; Поход/Испытания, вход/выход DEMO, сохранность хранилища, повторный вход и приоритет восстановления реальной попытки на четырёх ширинах в RU/EN.

`python scripts/check-cave-expedition-performance.py`: диагностический Chromium 360×640 с CPU 4×, кадры, память и длинное нажатие. Это **не измерение настоящего Android**. `python scripts/record-cave-expedition.py`: полная запись нового кода в реальном времени, без ускорения модели и искусственной победы. Видео и полный набор кадров доступны в артефакте существующей cave CI-проверки; ZIP для игры не требуется.

Исторические кадры и отчёты предыдущей P0-итерации (до новой комнаты): [бой](evidence/cave-p0-20261111/390-fight.png), [порталы](evidence/cave-p0-20261111/390-portals-1.png), [босс](evidence/cave-p0-20261111/390-boss.png), [победа](evidence/cave-p0-20261111/390-victory.png), [браузер](evidence/cave-p0-20261111/browser-report.json), [производительность](evidence/cave-p0-20261111/performance-report.json).

Настоящий Android, Telegram WebView, субъективное качество звука и итоговая UX-приёмка требуют проверки владельца на телефоне. Для этой итерации использованы два скриншота владельца: город как ориентир и фактический экран Пещеры с замечаниями о композиции и бое. Серверный multi-room, настоящее снаряжение и награды — отдельный P1, здесь не активируются.

## Воспроизведение разработчиком

```sh
npm run test:cave-expedition
npm run build:cave-preview
npm run test:cave-expedition:browser
python scripts/check-cave-expedition-performance.py
node scripts/build-journey-preview.mjs
python scripts/check-journey-browser.py
```

Сборщик использует тот же компонент, что игра; автономный HTML — технический smoke, не второй процесс публикации. Существующий Pages workflow публикует только проверенный main. Публичный SHA проверяется через `scripts/check-published-pages.mjs` после успешного deploy.
