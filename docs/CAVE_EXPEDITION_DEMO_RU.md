# TERRITORY — играбельная Пещера DEMO

Это отдельная тестовая сборка из ветки PR. Она **не заменяет действующую Пещеру** и не подключается к Supabase, аккаунту, настоящему инвентарю или камням. В `main` этот прототип не опубликован. Приёмка — только после личного теста владельца на телефоне.

## Как открыть на Android

1. Открыть PR → Checks → **Cave expedition - isolated playable artifact** → перейти к запуску Actions. Внизу страницы скачать артефакт `territory-cave-demo-<SHA>` (нужен вход в GitHub).
2. Распаковать ZIP через приложение «Файлы». Внутри находится **`territory-cave-demo.html`** — один файл примерно 4,3 МБ, все изображения уже внутри.
3. Открыть HTML через «Открыть с помощью → Chrome» либо другой браузер, разрешающий локальный HTML и JavaScript. Не выбирать текстовый просмотрщик или предпросмотр документа в GitHub. Интернет после скачивания не нужен.
4. Нажать **«Играть DEMO»**. В начале отряд бежит более 10 секунд. Можно включить **Авто** или использовать «Раскол», «Заслон», «Источник» вручную; базовые удары автоматические.
5. После каждой из первых двух комнат выбрать один из **двух порталов**. Герой подойдёт к выбранной арке. Левая/правая ветки действительно меняют фон и состав врагов. В третьей комнате после группы появляется **Собор Бездны**. Победить, увидеть тестовые трофеи и повторить забег с другим выбором.

Если Android передаёт HTML только встроенному просмотрщику файлов и не даёт запустить JavaScript, открыть сборку по локальной сети с компьютера: распаковать артефакт, в его папке выполнить `python -m http.server 4173 --bind 0.0.0.0`, на телефоне в той же Wi-Fi сети открыть `http://<LAN-IP-компьютера>:4173/territory-cave-demo.html`. Это не production и не требует игрового аккаунта. Сам HTML не делает сетевых запросов.

**Отдельного опубликованного HTTPS-адреса и Telegram staging-бота пока нет.** Обычный GitHub Pages показывает `main`, а не эту ветку. В управляемом браузере данной Cloud-среды `file://` запрещён административной политикой, поэтому проверялось открытие самодостаточного HTML через локальный HTTP и последующее отключение сети. Запуск через файловое приложение конкретного Android и настоящий Telegram WebView должен проверить владелец; его успешность здесь не заявляется.

## Что реализовано

- Один маршрут из **трёх комнат**, две пары порталов, четыре комбинации маршрута. По две группы из трёх врагов в первых двух комнатах, три врага и отдельный босс в третьей. Всего 16 врагов за забег.
- Отдельный мир с `heroX`, `enemy.worldX`, `cameraX`; автоматическое движение вправо, сближение, дальность, задержка попадания, отбрасывание, смерть и реальный счётчик убийств. Свободный пробег 11 секунд перед первой группой в каждой комнате; более двух стыков ближних сегментов.
- Слои: рисованная дальняя панорама, ближние скалы, частицы и мировая земля. Соседние панорамные сегменты отражаются попеременно, поэтому их кромки совпадают; камера движется независимо от слоёв. Размер изображений ограничен атласом, длинной 10000px-картинки нет.
- Пауза, остановка при скрытой вкладке, ограниченный шаг после задержки, очистка RAF/слушателей при закрытии, возврат к входу и перезапуск после победы/поражения.
- Энергия, откаты, три работающих умения и отдельный Авто. Модель боя намеренно простая и детерминированная, только DEMO. Спутники атакуют, получают споровый/боссовый урон, защищаются и могут погибнуть; главный герой остаётся ведущим.
- Оригинальные **Осколочник**, **Споровый парус**, **Янтарный глубинник**, **Собор Бездны**. В атласе каждого: idle, две фазы run, attack, hit, death. Босс крупнее, с собственной полосой HP, телеграфом удара и ударной волной.
- Сохранены исходные одобренные изображения викинга, Северного воина и Лесной целительницы. Дополнительно созданы четыре кадра бега для каждого. Другие облики героя и составы спутников в этот самостоятельный тест не подключены; реальные сохранения не читаются. Существующие исходные арты не заменены.
- Четыре рисованных биома: хрустальный разлом, грибной сад, янтарные недра и звёздный склеп. Ветка сердца разлома использует янтарную локацию с отдельным составом врагов и атмосферой.
- Выразительный экран победы с тремя **тестовыми** трофеями. Результат хранится только в памяти; нет «забрать награду» или записи предметов.

## Проверки и доказательства

- `npm ci`, `npm run typecheck`, `npm run build`.
- `node scripts/check-cave-systems.mjs`, `node scripts/check-cave-belt-attestation.mjs`, `node scripts/check-dark-stones.mjs`, `node scripts/check-adventure-client-ui.mjs`, `node scripts/check-adventure-receipt-adapter.mjs`, `npm run test:pve`.
- `npm run test:cave-expedition`: все четыре маршрута, дальность и попадание, ручные умения, HP/энергия/откаты, пауза, ограничение большого шага, 16 однократных смертей, босс, поражение, перезапуск, изоляция модулей.
- `npm run test:cave-expedition:browser`: Chromium, 320/360/390/430 × 720 CSS px, touch; живые кнопки двух развилок, различие комнат, победа/поражение, повтор, возврат, visibility/unmount; без прокрутки и внешних запросов. Дополнительно 360×640, сеть отключена после загрузки HTML. Сценарии ускоряют **шаги той же модели**, не подменяют HP/победы (кроме явной проверки поражения с HP=1).
- В артефакте `evidence/`: кадры движения, боя, обеих пар порталов, входа, другой комнаты, босса, победы и поражения на четырёх ширинах; JSON-отчёт.
- `python scripts/record-cave-expedition.py`: отдельная запись **в реальном времени** без перемотки/изменения игрового состояния, Авто и два касания порталов. Нужны Chromium и FFmpeg Playwright. Видео `evidence/real-time-run-390.webm`.
- Линтер новых TypeScript-модулей проходит. Общий `npm run lint` в исходном `main` имеет две посторонние ошибки: unused `now` в `ForgeScreen.tsx`, unused `MORTARION_HIT_COOLDOWN_MS` в `MortarionBossScreen.tsx`, плюс существующее предупреждение cleanup-ref. Эти экраны не изменялись.

Браузерная эмуляция не заменяет Android-устройство: плавность на настоящем телефоне, открытие файла его приложением и Telegram WebView ещё требуют личной проверки владельца. Серверный multi-room протокол, реальные награды, 100 этажей, сохранение/возобновление забега и звук сюда не входят. Обновление страницы сбрасывает DEMO.

## Воспроизведение разработчиком

```sh
npm ci
npm run test:cave-expedition
npm run build:cave-preview
# Открыть artifacts/cave-expedition/territory-cave-demo.html
npm run test:cave-expedition:browser
```

Сборщик повторно использует `CaveExpeditionPreview`, а не вторую реализацию игры. CSP запрещает любые соединения (`connect-src 'none'`); изображения встроены как data URL. Рабочие `floors.ts`, `ServerAdventureScreen.tsx`, серверные квитанции, SQL/Edge, Поход, Арена и Испытания не менялись.
