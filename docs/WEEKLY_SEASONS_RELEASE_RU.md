# Недельные сезоны TERRITORY — действующее решение 08.11.2026

**Единственный допустимый календарь активных недельных систем:** понедельник 00:00 UTC → следующий понедельник 00:00 UTC.

- ТОП-50 Арены: действующая серверная функция `arena_weekly_top50_v1`, клиентский календарь `arenaSeasonWindow`. Сохранить все реальные победы, их историю и положенные награды.
- Недельные задания: `weeklyQuestKey`, та же граница понедельника UTC.
- Отдельный старый «Недельный чемпионат»: **НЕ ЗАПУЩЕН И ОТКЛЮЧЁН** (`weekly_season_config_v1.enabled=false`). Не включать его SQL, cron, активацию, автоматические письма или выплаты. Данные/историю не сбрасывать.
- Исторические SQL-миграции и прежние тестовые сценарии не являются разрешением на откат календаря. Опасный повторный запуск старой миграции запрещён. Техническую историю Git не переписывать.
- Перед любым будущим запуском отдельного чемпионата сначала изменить серверный календарь на понедельник UTC, проверить изолированные тесты, границы календаря и однократную выдачу, затем получить отдельное разрешение владельца.

**Приёмка:** в реальном ответе сервера для действующего ТОП-50 `starts_at` и `ends_at` указывают на понедельники 00:00 UTC, недельные задания показывают ту же неделю; финал не создаёт повторных призов и не теряет старые результаты.

Это заменяет прежнюю инструкцию по установке старого чемпионата; выполнять её больше нельзя.
