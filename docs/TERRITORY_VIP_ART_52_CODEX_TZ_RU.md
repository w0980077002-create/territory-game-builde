# TERRITORY 1.0 — VIP 1–10: полное production-ТЗ для художника, генерации и Codex
**Редакция:** 05.11.2026. **Задача:** создать и внедрить все 52 новые самостоятельные иллюстрации VIP-зала для мобильной тестовой версии, затем дать владельцу проверить их в Telegram WebView. **Не считать макет, PR или зелёную сборку подтверждением личного приёмочного теста.**

## 1. Неподвижные правила проекта

- Визуальный эталон: старый тёмный красно-коричневый дуб/орех, выраженные волокна и сучки, толстая верёвка, кованый чёрный металл, заклёпки, чеканное тёплое золото. Яркое героическое викинг-фэнтези, но не плоские emoji, не пластик, не «казино», не кошачьи мордочки вместо зверей.
- 52 — количество **новых сюжетов/изображений**, не 52 перекрашенных копий. Каждый сюжет отдаётся как отдельный мастер PNG с альфой (кроме фона) и оптимизированный WebP для клиента. Это две версии одного рисунка, а не 104 разных иллюстрации.
- Для каждого рисунка ввести единую перспективу, направление света сверху слева, тёплый контровый свет, последовательный размер и контраст. Силуэт уровня должен различаться даже на маленьком экране без текста.
- **Прозрачный фон для всех ассетов, кроме единственного фона сцены.** Не запекать задник, облака, текстовые ярлыки, чужих персонажей и рамку в корону, сундук, трон или облик. PNG/WebP с реальным alpha channel, без шахматной сетки и без белого ореола.
- Во всех файлах: один объект/один субъект (кроме явно составного рангового портрета), без срезанных лап, ног, оружия, ушей, рогов. Не использовать защищённые чужие изображения, логотипы игр или рисунки из интернета как финальный арт.
- Текущие 10 значков `public/assets/territory/vip/badges/vip-01.svg` … `vip-10.svg` **перерисовать/заменить** в тех же путях как 10 ранговых пиктограмм в рамках этой задачи, но они являются **заменой существующих файлов**, а не частью 52 новых. Существующие 6 VIP-рамок (`cosmetics/frames`) визуально проверить и при необходимости улучшить, сохранив совместимость. Не выдавать старые SVG за новые 52 рисунка.
- Иконки не должны выглядеть как разный рандомный набор: единая геометрия щитов, увеличение качества материала по рангу, но с узнаваемой индивидуальной эмблемой. Цифры ранга выводятся **HTML-текстом**, не запекаются в иллюстрации.

До согласования цен убрать любые намёки на рабочую покупку. VIP 10 называется «Легенда TERRITORY»; статус «Основатель» — отдельный титул, только если он действительно предоставлен.

## 3. Формат, экспорт, мастер-файлы

Все финальные клиентские изображения класть под `public/assets/territory/vip/v2/` по таблице ниже. Источники PNG/проект художника хранить в отдельном каталоге исходников, не загружать гигантские исходники в сборку клиента. Схема имён: латиница, нижний регистр, дефисы, нули `01`–`10`, без пробелов и случайных суффиксов. Выход WebP с прозрачностью/цветовым профилем sRGB, оптимизация без каймы по краям.

Мастера: фон 1440×900; плакетка 1200×300; подиум 1200×500; ранговые герои и гуманоидные скины 1024×1536; сундуки/короны/гербы 768×768; ауры 1024×1024; звериные скины 1536×1024; троны 1024×1280. На мобильном интерфейсе не растягивать картинку: `object-fit:contain`, сохранять пропорции и центр массы; свечение ауры отдельно, без сдвига сетки. Визуальные безопасные отступы 6–10% по краям мастер-холста, не укорачивать фигуру.

**Бюджет загрузки:** цель ≤250 КБ для отдельной короны/герба/сундука, ≤450 КБ для героя/скина/трона, ≤550 КБ для сцены; при необходимости качество подбирается визуально, а не ценой сильных артефактов. Первоначально загружать только выбранный VIP, четыре видимых блока и используемые украшения; прочие через lazy loading. Размер/алфа проверяются автоматически.

## 6. UX/логика мобильного VIP-зала: точное поведение

**Экран 1, верхняя часть:** высота шапки ≈46–52 CSS px, один заголовок «ЗАЛ VIP» / «VIP HALL», вернуться назад одной кнопкой. Никакой длинной горизонтальной прокрутки ряда рангов. Блок рангов занимает ≈105–125 CSS px.

**Экран 2, центральная сцена:** высота ориентировочно 170–210 CSS px, индивидуальный `vip-main-XX` в режиме «Образ ранга», **отдельно** реальный герой игрока (`getAppearanceIcon(game.appearance)`) в режиме «Мой герой». При переключении героя/спутника настоящий сохранённый персонаж/спутник остаётся прежним до легитимной операции. У сцены только один основной объект, фон `scene`, подиум `ui`, предметы — независимые слои. Не дублировать фигуру поверх самой себя.

**Экран 3, навигация:** три понятные вкладки: «Привилегии» / «Примерка» / «Сундуки». Показывать одну вкладку одновременно. Смена VIP мгновенно обновляет тему, ранговый портрет, доступные украшения и образ сундука **без изменения `realVip`**. Различать «Ваш VIP: N» и «Просмотр VIP: M»; низкий VIP может смотреть любой ранг.

**Примерка:** компактные категории «Рамка», «Корона», «Аура», «Герб», «Облик», «Трон» (существующую «Рамку» не скрывать; расположить 3×2 на 320 px, не сжимая подписи); бесплатный просмотр без ограничений. Стрелки переключают конкретные арт-объекты категории. Вкладка «Облик» должна показывать либо один цельный облик героя, либо одного спутника — никогда два наложенных силуэта; скины 7 и 9 относятся к спутнику, 5/6/8/10 — к герою. «Надеть» только при подтверждённом VIP и совместимом объекте; в тестовой версии неподключённые облики имеют кнопку «Только просмотр».
