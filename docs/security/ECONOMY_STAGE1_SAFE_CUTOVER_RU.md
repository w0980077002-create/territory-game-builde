## Важно: подготовка ещё НЕ равна защите экономики
Пока приложение вызывает \`saveCloudSave()\` для полной записи \`game_state\`,
нельзя отзывать его UPDATE права. Иначе реальные игроки потеряют сохранение.
Статус защиты — **НЕ ГОТОВО**.

## Условия переноса в рабочую базу
1. Внешняя резервная копия текущей базы и **проверка восстановления**.
   Копия таблиц в том же Supabase — не полноценный backup.
2. Тестовая база с обезличенными персонажами, в том числе старым снаряжением,
   письмами и активными билетами игрового зала.
3. Реализованные серверные транзакции для покупок, наград, крафта и боёв:
   расход / начисление / receipt атомарно, под одним блокированием игрока.
4. Повтор по одному operation_id никогда не списывает и не начисляет дважды.
5. На ошибку сети — повтор **того же** ключа, не выдача новой награды.
6. Переход клиента на RPC, полный регресс Android/iOS, тест двух устройств.
7. Только после этого REVOKE на валютные колонки и клиентский инвентарь,
   плюс аудит RLS и SECURITY DEFINER.
8. Ручная проверка подозрительных операций, без автобанов и без обнулений.
