# TERRITORY — накопительный журнал референсов Тёмного царства / Тёмной энергии

**Дата создания:** 10.11.2026. **Статус:** действующий накопительный архив; дополнять при каждой новой передаче фото, видео и уточнений владельца. **Владелец задачи:** Claude Code по issue #314. **Общее ТЗ:** [TERRITORY_DARK_CAVE_LOOTBORN_PRO_TZ_RU.md](TERRITORY_DARK_CAVE_LOOTBORN_PRO_TZ_RU.md).

## Правило работы с новыми материалами

1. Владелец присылает видео/скриншоты Call of Odins или Lootborn Warriors и устно комментирует механику. **Все принятые материалы регистрировать в этом журнале**, не терять старую доказательную базу и не создавать десятки конкурирующих ТЗ.
2. По подтверждению владельца, Call of Odins использует ту же основную механику, что Lootborn Warriors, меняя названия и картинки. Поэтому кадры Call of Odins — **основной доступный референс игрового поведения Тёмной энергии**, но каждый факт о кнопках/получении/статах отделять от догадок о скрытых алгоритмах.
3. Оригинальные десять JPEG из сообщения владельца 10.11.2026 сохранены в **приватной ChatGPT Library**: `/TERRITORY/Dark-Cave-References/2026-11-10-screenshots/`. Это не GitHub-URL; облачный Claude Code не получает доступ к ChatGPT Library автоматически. Дубли в исходном корне Library не удалялись. **Не копировать в публичный репозиторий оригинальные изображения чужой игры**; для конкретной визуальной сверки использовать разрешённый доступ к референсам, уже существующие 15/16 кадров в GitHub, либо предоставить Claude изображения по отдельному каналу.
4. При новой партии: сохранить оригиналы без перерисовки; записать исходные имена, порядок и видимые детали; уточнять источник и тип игрового экрана; пополнять таблицу, не стирать ранее утверждённые правила. Записи о просмотренных кадрах **не превращать в вымышленные проценты дропа, универсальные правила всех версий, доказательства серверной реализации**.
5. В TERRITORY воспроизводить функциональный игровой процесс на собственных коде, именах, шмотках, визуале и звуках. Никогда не заменять основную экипировку героя дополнительной Тёмной энергией и не смешивать инвентари. Новые предметы, их характеристики и сеты должны реально сохраняться и влиять на бой после безопасной серверной активации и приёмки.

### Сопоставление с видеодоказательствами, уже имеющимися в GitHub

В репозитории **уже** имеются прошлые прямые кадры видео: `docs/reference-screenshots/call-of-odins-2026-11-06/` (15 screenshots) и `docs/evidence/call-of-odins-20261106/` (16 кадров по прежнему видеоатласу), с таймкодами в [основном ТЗ](TERRITORY_DARK_CAVE_LOOTBORN_PRO_TZ_RU.md). Эта новая партия дополняет их прежде всего:
- **реальными карточками атрибутов, сетами 2/7, сравнением +/− силы и кнопкой «Экипировать»** — ранее это было менее подробно зафиксировано;
- **уровнями тёмных предметов 188–229 и Lv.50 на карточке**, собственным складом и индикацией возможного улучшения;
- отдельным **справочником древних/перерождённых** типов тёмной экипировки;
- образцами **многокатегорийных послебоевых наград** и тематических босс-сцен, но **без утверждения**, что три победных окна обязательно относятся к Пещере, пока не проверена видеопоследовательность.

### Приоритетные дополнения к ТЗ для Claude после этой партии

1. Два класса экрана: **список только реально принадлежащих игроку тёмных экземпляров** с отдельным cap и **справочник доступных/неоткрытых типов и комплектов**. Не смешивать `catalogue` и `owned instances`.
2. Экран **сравнения в две колонки**, `equipped` vs `candidate`; индивидуальные параметры, сравнение силы, активируемые наборы/умения, подтверждение замены и последствия разбора. Проценты и миллиарды чужого аккаунта — не баланс TERRITORY.
3. Реальный независимый дополнительный комплект, отдельные 12 позиций/UUID/владение/статы, не замещающие семислотовую основную экипировку персонажа. Для **2/7** на скрине сет состоит из **семи частей**, а не только из шести: нельзя догматично кодировать все комплекты 6/6.
4. Фиксация нового предмета после победы: поступление в тёмный склад **только по проверенной серверной квитанции**, без смешивания с обычными наградами, без двойного лута и без конвертации чужой валюты 1:1.
5. Тематические боссы, длинный/короткий бой и HUD оценивать по полным роликам; не копировать чужую сцену или названия персонажей как нашу графику.
