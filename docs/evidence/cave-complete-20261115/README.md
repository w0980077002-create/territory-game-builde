## Во что играть

`npm run build:cave-preview` → `artifacts/cave-expedition/territory-cave-demo.html`. Это тот же компонент, что в игре, с артами внутри HTML, без отладочного управления, аккаунта и сетевых подключений. Нажать «В путь». Базовые удары и движение автоматические; четыре навыка, семь зелий, Auto, автозелья, скорость и пауза доступны. Дважды выбрать арку; победить босса; открыть добычу и изменить снаряжение. Проверить повторный вход.

**Все вещи, стартовый комплект, награды и валюта здесь локальные тестовые. Ничего не начисляется на серверный аккаунт.** Оформление игры сохранено как в текущем main. Старое размещённое Sites-превью не обновлялось и не подтверждает этот SHA. HTML, полная запись и кадры упаковываются существующим workflow Cave expedition в артефакт PR.
