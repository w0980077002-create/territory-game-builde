## 2. Один вертикальный сценарий — что пользователь реально увидит

В существующей «Новая экспедиция · тест»:
1. Сразу крупная арена/пещера с компактным HUD и читаемыми кнопками без тройных внешних шапок. Без вертикального скролла в бою. Можно выйти/вернуться, обычная серверная Пещера не ломается.
2. Герой и **два активных спутника** отдельно, с якорем стоп на одной земле и глубиной. Враги — справа и смотрят налево. Не перекрывать лица HP, текстом, VFX, панелями; соблюсти безопасные зоны Telegram WebView.
3. Первая осмысленная встреча быстро; сохраняется настоящий бег вправо и параллакс. В кадре — **разные противники** из имеющегося каталога (после получения ZIP — визуально новые одобренные 1–3), различимые HP/состояния.
4. Игровые события дают **реальное** idle → run → attack → hit → death, хотя бы для выбранного героя и одного типа противника + босса на первом P0 проходе. Источник — engine events, не таймер «махания» поверх неподвижного постера. Остальные 21 получают поэтапное подключение после первой проверенной сцены. Не обещать 21 законченный rig, если есть только 21 RGBA still.
5. Три умения имеют реальные эффекты и стоимость энергии/cooldown. «Авто навыков» OFF отличается от ON; базовая автоатака остаётся. Один телеграф босса контрится «Заслоном», «Источник» реально лечит, «Раскол» действует по нескольким целям; бой требует решений, но без непредупреждаемых убийств.
6. Два настоящих портала в сцене, выбор 1/2 для каждой из двух развилок, выбор действительно меняет следующий биом/тип врага. Победа/поражение/пауза/перезапуск честные, трофеи **ТЕСТ** ничего не начисляют.
7. Локальные многослойные VFX, без лагов и декоративной подмены боя. У босса 2–3 читаемые фазы, атаки, реакция на удар и поражение. Масштабные боссы могут стоять в 3/4 ракурсе, но явно смотрят на героев слева.
8. Проверить на Android WebView настолько, насколько реально доступно; отсутствие доступа к физическому телефону честно пометить и приложить результаты браузерного smoke.

**Не превращать задачу в полный редизайн мира:** сначала один настоящий вертикальный проход, потом цикл 21 персонажа/набор биомов.

## 5. Выходной критерий

**Готов P0** = существующая «Новая экспедиция · тест» стала **действительно играбельной**, 1 герой + 2 спутника стоят правильно, враги справа влево, действия реально управляют боем, один босс фазный, экран удобен, Pages выложен и можно открыть на телефоне; нет ни одного изменения реальных сохранений/экономики. Пакет v2 сам по себе **не игровая интеграция**. Вывод о 21 персонаже делать отдельно по факту.
