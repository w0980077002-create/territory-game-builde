# TERRITORY — изменения пакета v2 (11.11.2026)

## Что изменено
На основе замечания владельца о направлении противника в бою заменены **только 4 PNG** и их производные WebP превью:
- `minibosses/senior_driller.png` — гном-бурильщик, бур направлен на левую команду
- `minibosses/moss_eater.png` — мшистый голем, голова/корпус повернуты влево
- `bosses/fungal_king.png` — Грибной король Морока, лицо и активная магическая рука обращены влево
- `bosses/minotaur_echo.png` — Минотавр Эха, лицо и боевой топор направлены влево

Остальные 17 PNG **побайтово идентичны** исходному пакету v1 (контроль SHA256 из `manifest.json`).

## Проверено автоматически
- 21/21 отдельных PNG в режиме RGBA;
- альфа-канал 0…255, прозрачность по четырём углам;
- 21 контрольная SHA256 и исходные эталоны в архиве;
- маски/размер/стоп-кадры WebP для предварительного просмотра;
- все 8 обычных врагов помечены ориентированными `left`.

**Важное ограничение**: визуально направленные влево стоп-кадры — это ещё не настоящие анимации. Постерная версия и геймплейные спрайты не равнозначны. Проверки реального качества арт-локов, RTL/спрайт-риг, Telegram WebView, GitHub Pages и боевого UX не выполнены. Изображения здесь не подменяют существующих персонажей в live игре.
