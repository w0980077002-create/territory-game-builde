# TERRITORY 1.0 — T18: Последователь / Призыв / Тёмная энергия / Морские походы

Статус 28.10.2026: **готова визуальная часть и контракт экранов**, подключённые реальные механики — только существующие пять спутников. Экраны призыва, реликвий и моря не открыты игрокам, поскольку для них нет утверждённого серверного контракта.

## 1. Последователь — реально работающие функции

- Переработан `src/components/FollowersPanel.tsx`: 5 портретов из **утверждённого набора** `getFollowerArt`, выбор одной карточки для деталей.
- Верхняя панель показывает **действительно выбранного** спутника `selectedFollower(state)`, а не фальшивый отряд из трёх бойцов.
- В деталях реальные атака, защита, уровень, условие открытия, стоимость обучения, прогресс и доступность действия.
- Кнопки используют **только старые** `selectFollower`, `trainFollower`, `followerTrainingCost`. Сохранение и стоимость наследуют существующую логику; арена не получает бонусов спутников.
- Стиль: деревянная вывеска и настоящие пять иллюстраций, без несуществующих звёзд, пробуждения и фальшивых бонусов.
- Вкладка «Спутники» остаётся в инвентаре. Для совместимости с существующими тестами не изменены названия и пути источников.

## 2. Остальные три раздела — готовые экраны под серверный контракт

Пути: `src/components/expansion/ExpansionPanels.tsx`, `expansionPanels.css`.

### Призыв — `SummoningPanel({language, status?, busy?, onSummon?})`
- Карточки с оригинальными утверждёнными изображениями, имя, описание, цена, только если цена **реально пришла с сервера**, и бесплатные попытки по **серверному ответу**.
- Без `status` показывает, что сервер не подключён. Кнопки действий отключены без обработчика и подтверждённой доступности.
- Codex: определить схему пула, шансы, периоды попыток, цены и результат операции. Никогда не добавлять клиентские награды.

### Тёмная энергия — `DarkEnergyPanel({language, status?, busy?, onEquip?, onDismantle?})`
- Поддерживает список **серверных** слотов и реликвий, их атрибуты, редкости, выбор и фильтр, смену слота, подтверждение разбора.
- Не приравнивать эту систему к отдельному **Фонду тёмной энергии**.
- Без `status` — сообщение «не подключено»; кнопки экипировки/разбора отключены без подтверждённого обработчика.
- Codex: определить отдельные IDs, защиту владельца предметов, атомарные equip/dismantle, состав наград разбора, реальные слоты.

### Морское плавание — `SeaVoyagePanel({language, status?, busy?, onClaim?, onOpenShips?, onOpenRanking?})`
- Список кораблей, статус плавания, возвращение, доход и рейтинг показываются **только из серверных данных**.
- Кнопка получения дохода недоступна без `ship.readyToClaim` и серверного обработчика `onClaim`.
- Codex: утвердить модель плаваний, цены кораблей, условия запуска и начисления дохода, рейтинг и таймер; не включать выплаты до готовности.

## Интеграционная последовательность

1. Codex публикует отдельные модели и серверные обработчики с проверкой доступа/атомарностью, **в staging, без выкладки в production**.
2. Компоненты принимают типизированные `status` и `on*` callback. Отдельные экраны/переходы добавляются **только после подключения**.
3. Проверка на Android и iPhone. Сохранение активного спутника, уровня и материалов не меняется при открытии других режимов.
4. Не смешивать работу с TERRITORY 2.0, не трогать пять нажатий для входа в админку, не менять старую механику без отдельного согласования.
