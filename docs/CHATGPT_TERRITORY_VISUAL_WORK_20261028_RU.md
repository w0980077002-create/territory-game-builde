## Первая самостоятельная реализация ChatGPT

1. Оригинальный настраиваемый каталог пяти веток по три умения в каждой и рун; не путать руну с навыком.
2. Адаптивная изолированная сцена в ярком стиле TERRITORY; существующие ассеты героя, противников, спутников, без замены утверждённых картинок и без механических SVG-кукол.
3. Локальная визуальная демонстрация боевых движений с временными событиями (чётко обозначать её как preview, никаких реальных наград), после чего подключение к единому потоку `IdleCombatEvent`.
4. UI экрана «Навыки»: пять рядов по три, золотое выделение выбранного; три пассивных; подробности выбранного умения, две совместимые руны, КД, источник эффектов. Все тексты оригинальные и читаемые с телефона.
5. Эффекты: огонь, лёд, молния, следы критического удара, щит, метка точности. Должны возникать на контакте и быстро исчезать. Ограничить одновременные VFX, добавить reduced-motion.
6. Проверка `npm run typecheck`, тестов каталога и ручной визуальной проверки; на слабых телефонах не допускать зависаний/многократных реактовых ререндеров за тик.
