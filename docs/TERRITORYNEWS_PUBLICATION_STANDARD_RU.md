# TERRITORY — обязательный стандарт публикаций TerritoryNews

**Утверждено владельцем 10.11.2026 по фактическому посту Мортариона в Telegram.** Применять ко всем будущим публикациям канала **@TerritoryNews**, связанным промопостам и инструментам подготовки сообщений.

## 1. Форматирование Telegram (проверять в настоящем клиенте)

- **Настоящий жирный шрифт на кириллице** для коротких заголовков, названий событий, самых важных чисел и ключевых наград.
- При необходимости — *курсив*, подчёркивание, цитаты с цветной полосой, кликабельные ссылки и уместные эмодзи.
- Достаточно коротких абзацев и читабельных отступов; важное видно с телефона сразу. Не перегружать текст капсом, эмодзи, длинными полотнами.
- **Не выдавать Markdown `**так**`, HTML-теги и обычную вставку из чата за готовое Telegram-форматирование.** При отправке ботом использовать `sendMessage` c `parse_mode: HTML` и допустимыми тегами `<b>`, `<i>`, `<u>`, `<blockquote>`, `<a>`; обязательно корректно экранировать пользовательский текст. Проверять фактическое сообщение в Telegram после публикации.
- Источник эталона — реально опубликованное владельцем сообщение о Мортарионе (скриншот 10.11): заголовок и несколько ключевых смысловых блоков **жирные кириллические**, весь остальной текст обычный, разделён на короткие абзацы.

## 2. Стиль и аудитория

- **TERRITORY — международная игра.** В глобальных игровых новостях не указывать какой-либо один город как базовую часовую зону или центр проекта, в частности не добавлять слово «Киев» или его варианты.
- Для времени события предпочитать **таймер внутри игры**, а когда нужен точный момент — **UTC** (с явной пометкой). Даты и сроки подтверждать по текущему серверному состоянию; не придумывать тайминги.
- Текст **короткий, ясный, энергичный**, без технических подробностей. Что произошло → правила/цифры → награды → куда нажать. Не обещать неподтверждённых наград, вероятностей и функций.
- Заголовки, жирные/курсивные акценты и цитаты должны **работать в самом Telegram**, а не только в рендере ChatGPT, GitHub или превью.

## 3. Публикация и безопасность

- Канал: **@TerritoryNews**. Бот **@TeritoryGameBot** уже назначен администратором. Для публикации требуется только право «Отправка публикаций»; нельзя выдавать лишние права на удаление/изменение чужих постов и управление каналом.
- Предпочтительный путь: **Админка → TerritoryNews → предпросмотр → подтверждение публикации**. Используется защищённая Edge Function `territory-news`, а не копирование обычного текста в Telegram.
- Публиковать **только после явного согласования владельцем конкретной версии текста**. После отправки проверять реальный результат и подтверждение Telegram; не сообщать «опубликовано», если это не установлено.
- Не хранить токены Telegram в GitHub или браузере, не обходить авторизацию админки. Не добавлять скрытые автоматические рассылки, повторы или дубли.
