## 3. Прямое применение к TERRITORY 1.0 — зарезервированные ценовые уровни

В магазине TERRITORY предлагается позже создать *оригинальные* десять наборов с той же лестницей цен **0.99 / 1.99 / 3.99 / 5.99 / 11.99 / 17.99 / 22.99 / 34.99 / 59.99 / 119.99 USD** как референс. Отдельный высокий уровень по аналогии с Pack 11 рассмотреть только после определения региональной цены.

Для будущих SKU завести поля `sku`, `source_reference_name`, `nominal_usd_tier`, `purchase_channel`, `region`, `contents_confirmed`, `contents_config`, `availability_window`, `limit`, `server_receipt_id`. **Не продавать пустые или вымышленные пакеты**, не завязывать реальные платежи на локальное состояние клиента.

- Линейка товаров для разработки: начальный пакет, тематические наборы улучшений героя, ресурсы профессий, спутники, VIP/привилегии, сезонные наборы. **Это наша будущая авторская комплектация, а не подтверждённое содержимое Lootborn.**
- Обеспечить реальную ценность дорогих наборов при разнице с дешёвыми; сохранять баланс, не обнулять тестеров.
- Для **Telegram Mini App** цифровые покупки должны оформляться через **Stars (XTR)**; долларовые цены — только ориентир, а не обещание точного курса к Stars. Android/iOS имеют отдельные платёжные правила.

- **Crazy Monkey и другие игры зала** остаются на невыплатной игровой валюте.
- Цены должны обновляться конфигурацией сервера по стране/каналу; изменения каталога требуют отдельного запуска платежей и проверок.
