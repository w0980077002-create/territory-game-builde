## Где открыть в ветке PR

Боевой экран → Тёмная пещера → «Новая экспедиция · тест» →
**«Арт v2 · 21 стоп-кадр»**.

Это вкладка в существующем компоненте DEMO, без нового игрового режима.
Герой и два спутника слева, выбранный противник справа; выбор одного из
трёх героев меняет только демонстрационный облик. Стрелки и список позволяют
просмотреть все 21 изображения; «Прозрачность» включает шахматный фон.
Размеры сохраняют пропорции, прозрачные поля учитываются для линии земли;
зеркалирования нет. При ошибке изображения показано имя недоступного спрайта,
навигация остаётся рабочей. Возврат открывает прежнее DEMO.

Новые изображения загружаются по потребности после открытия вкладки;
PNG-мастера и оригиналы не включаются в игровой bundle. Модуль вкладки
также загружается лениво. Существующий offline preview builder включает
все WebP для воспроизводимой проверки без сети — это дополнительный способ
проверить тот же компонент, а не замена входа внутри игры.

**Это проверка статичного арта.** Нет новых idle/run/attack/hit/death кадров,
rig, новых боевых механик, покупок, выдач или серверного сохранения. Во время
просмотра арта движок DEMO остановлен. Существующий бой DEMO использует
свои прежние анимации и баланс. Нельзя считать этот PR готовностью 21 живого бойца.

## Воспроизводимые проверки

```sh
python scripts/check-approved-characters-v2.py
# Дополнительная сверка с извлечённым ZIP:
python scripts/check-approved-characters-v2.py --source /tmp/territory-art-validation/TERRITORY_ART_PACK_2026-11-11_v2
npm run typecheck
npm run lint
npm run build
npm run test:cave-expedition
npm run build:cave-preview
node scripts/build-cave-expedition-preview.mjs --test
python scripts/check-cave-expedition-browser.py
python scripts/check-approved-characters-v2-browser.py
```

Результаты: проверка арта, typecheck, build, адресный ESLint изменённых файлов,
тесты движка и оба браузерных smoke прошли. Общий `npm run lint` завершился
с тремя существующими ошибками: неиспользуемые `now` в `ForgeScreen.tsx` и
`trialLoot.ts`, `MORTARION_HIT_COOLDOWN_MS` в `MortarionBossScreen.tsx`; также
есть предупреждение cleanup ref в `MortarionBossScreen.tsx`. Эти три файла
совпадают с исходной веткой PR и не менялись в этой работе.

Python-проверкам нужны Pillow и Playwright, браузерным — Chromium.
Для локального просмотра без авторизации можно открыть уже существующий
`artifacts/cave-expedition/territory-cave-demo.html`, собранный тем же builder.

Браузерные проверки: **320×568, 360×640, 390×808, 430×720, 640×360**,
все 21 персонажа на каждом размере, RU/EN, touch, reduced motion, отсутствие
пересечений и скролла, кнопки не менее 44 px, переключение фона, циклическая
навигация, возврат в DEMO, отсутствие записей в local/sessionStorage и cookies,
отсутствие внешних запросов. Дополнительно: 21 фактический URL собранных WebP
с префиксом `/territory-game-builde/`, повреждённый спрайт и восстановление
навигации после него. Существующий браузерный smoke DEMO проверяет все четыре
маршрута, босса, умения, победу/поражение, перезапуск и жизненный цикл.

Отчёты и избранные скриншоты находятся в
[`docs/evidence/characters-v2-20261111/`](evidence/characters-v2-20261111/).
Полный набор локальных снимков — в `artifacts/cave-expedition/characters-v2-evidence/`.
Проверен Chromium с эмуляцией Android UA/touch. **Физический Android и Telegram
WebView не проверены**; эмуляция не заменяет приёмку владельца.

файлов) выявила конфликт со свежим `origin/main` в

сцену/умения пещеры. Проверенный снимок PR работоспособен сам по себе;
перед будущим слиянием необходимо согласовать обе версии этого компонента
и повторить проверки на объединённом коде. В этой работе merge/rebase не выполнялись.
