# Мортарион: корона Повелителя душ

Статус: локальная реализация и браузерная проверка завершены; публикация и мобильная приёмка пока не подтверждены.

Исходная опубликованная реализация: `b9b542b` (#515). Утверждённый AVIF сохранён побайтно (SHA256 `7830e264d961ba609d62f87fbee9b80258e34600f52ca1a15955a38f1b936624`). Новый арт не рисовался. SVG в компоненте — только окна кадрирования исходной картинки, без рисованных замен рамки.

Корона поднята в верхнюю часть сцены; боковые камни уменьшены пропорционально и вынесены к краям между нижними слотами. Нижний орнамент позиционируется отдельно, с адаптивным отступом над уровнем. Корона и все камни сохраняют пропорции; по высоте меняется только узкая часть боковых направляющих без камней. Геометрия героя, семи слотов и плашки уровня не изменена.

Пробуждение длится 850 мс и запускается после загрузки картинки: проявление, локальное пурпурное свечение рубина, небольшой отблеск. Постоянное свечение меняется с минимальной амплитудой за 7,9 с. Три одиночные искры имеют разные интервалы 17,3 / 23,1 / 19,7 с; локальный отблеск — 13,7 с. Анимации меняют только opacity/transform, без canvas, таймеров и покадрового React. При reduced motion новые анимации отсутствуют. Все декоративные слои пропускают нажатия. AVIF fallback — lossless WebP из тех же декодированных пикселей, а не другая рамка.

## Проверки

- `npm run typecheck`, `npm run build`, полный `npm run lint`, адресный ESLint двух TSX — PASS.
- `npm run test:mortarion` — PASS, включая реальные контракты наград (статический тест, без вызовов production).
- `node scripts/build-profile-preview.mjs && python scripts/check-mortarion-frame-browser.py` — PASS. Chromium `/usr/bin/chromium`; можно переопределить `CHROMIUM_PATH`, каталог скриншотов — `MORTARION_EVIDENCE`.
- На 320/360/390/430: обычный герой → ТОП-1 → ТОП-2–3 → ТОП-4–10 → повторный ТОП-1 → обычный. Все семь слотов нажаты в каждом состоянии; нет горизонтальной прокрутки. Размеры и взаимные положения героя/слотов/уровня совпадают с обычным состоянием. Уровень, XP, характеристики, ресурсы и полное состояние фикстуры не меняются.
- Дополнительная фикстура с семью надетыми предметами уровня 41 сохраняет все предметы и уровни после всех переключений. Это проверка отсутствия клиентских мутаций, не доказательство серверного сохранения.
- Reduced motion: ни одной новой анимации. Принудительный отказ AVIF: загружается WebP и тот же арт во всех окнах кадрирования. Повторное включение ТОП-1 перезапускает пробуждение, переход к другому рангу удаляет эффекты.

Supabase, серверные функции, экономика и сохранения не менялись и не вызывались для тестов. Физический Android, Telegram WebView и производительность на реальном телефоне **не проверялись**. Для мобильной приёмки нужно оценить плавность и рисунок в Telegram на устройстве; браузерная проверка не заменяет эту оценку. После слияния требуется успешный Pages workflow и `node scripts/check-published-pages.mjs` с SHA релиза. Пока они не подтверждены, считать работу опубликованной нельзя.
