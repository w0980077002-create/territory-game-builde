# ПРИЁМКА ВЛАДЕЛЬЦА: TERRITORY / ТЁМНАЯ ПЕЩЕРА — CLAUDE

**Всё ниже проверяется на ИЗОЛИРОВАННОМ тестовом прототипе, а не на реальном сервере.** Файл только для проверки работы Claude; в main не сливать автоматически.

## 1. Минимальная непрерывная игровая запись
На видео с мобильным соотношением сторон и в живом браузере видно без склеек:
1. Вход в тестовую Тёмную пещеру; **HP и энергия** и название главы/этажа.
2. Герой **физически движется вправо в мировых координатах**; ближайшие декорации смещаются быстрее дальних; камера открывает новый участок, не только прокручивает текстуру.
3. Два спутника идут рядом позади, **не перекрывают** героя; враг появляется впереди и останавливает путешествие.
4. Бой — попадания визуально достигают врага, HP врага/героя меняются, персонажи реагируют.
5. Победа → герой реально **продолжает бег и открывает новую часть локации**, затем развилка → следующий участок → босс. Не показывать просто тот же статичный задник с другой надписью.
6. После паузы весь тестовый мир заморожен: ни камера, ни бои, ни энергия, ни таймеры/спутники не тикают. После возобновления без скачка/двойной награды.
7. Обновление страницы возвращает тот же **тестовый** забег/позицию, без влияния на настоящий аккаунт.
