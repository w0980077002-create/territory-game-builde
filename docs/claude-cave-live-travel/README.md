- Начни с **двух существующих модулей — engine.ts + renderer.ts**: реальные путешествия по мировым координатам, плавная камера, разные скорости для заднего/среднего/ближнего слоя, грунт и преграды. Повторно используй готовые сцены из `public/assets/territory/cave-expedition/`, добавь небольшое число необходимых *оригинальных* тайлов/слоёв, только если они нужны для настоящего параллакса. Не делай «фальшивый бег» с движущейся текстурой при неподвижных локациях.

Пауза останавливает ВСЁ движение, боевые таймеры и VFX тестового мира. Убедись, что reload/checkpoint возвращает тестовую позицию, события не повторно награждают.

## 3. HUD ПЕЩЕРЫ — САМОЕ ВАЖНОЕ, НЕ ПУТАТЬ 7 И 12
- **НЕ СТАВИТЬ В ВЕРХНИЙ HUD ПЕЩЕРЫ 7 обычных иконок**. Это старый `PlaytestGear` — он сейчас действительно выводит 7 стандартных предметов, чем владелец недоволен. **Обычную экипировку аккаунта не удалять и не изменять в других разделах.**
- **ВИДНЫ СРАЗУ на основном боевом экране:** 12 **ДОПОЛНИТЕЛЬНЫХ** темных слотов Umbra (с реальными существующими тёмными иконками, корректными обозначениями усиления) + **13-я отдельная позиция Крыльев**, не внутри 12. Использовать текущие `UMBRA_SLOTS`, один текущий тестовый `umbra_loadout`/`umbra_inventory`, не создавать второй склад. Например, адаптивная **2×6 лента тёмных слотов и отдельные крылья** на мобильном 320 CSS px; **все 13 видны одновременно без открытия отдельной вкладки и без горизонтальной прокрутки**. По нажатию предмета/крыльев открывается существующая полная панель снаряжения/примерки. Без многократного дублирования и без уменьшения игровой сцены до неподвижной мини-карточки.
- **Оставить и сделать реально рабочими в тестовом режиме:** HP, энергия, уровень персонажа отдельно от этажа/волны, глава Пещеры и прогресс, карта/цель, скорость x1/x2, Auto, настройки, пауза, четыре навыка, **7 эликсиров пояса (это не 7 шмоток!)**, Благословение, Почётные звания, Тёмное снаряжение/самоцветы, **постоянные нижние 7 кнопок** (Город / Инвентарь / Герой / Бой / Карта / Игры / Клан). Не удалять кнопки ради компоновки; при нажатии происходят тестовые действия, а не декорация.
- UX референса: **красный выразительный HP-орб слева, синий орб энергии справа, центр — компактные уровень/прогресс**, весь HUD натуральный тёмный дуб, кованый металл, тёплое золото, текст короткий/понятный, без зеркальных/волнистых орнаментов. Окно выбора или полного описания вещи может иметь внутренний скролл; сам нижний бар не должен уезжать.
- Отдельно проверить маленькую **высоту** экрана и Android browser/Telegram WebView: 320/360/390/430 CSS px. Сильная визуальная плотность — не повод убрать согласованные функции. Если все 13 не помещаются с приемлемой читаемостью/кликабельностью, сначала предложить адаптивное решение внутри того же экрана, показать владельцу и **не самовольно заменить 12 на 7**.
