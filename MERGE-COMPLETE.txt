TERRITORY — DEEP MERGE BUILD

This patch is assembled for territory-game-builde.

Merged direction:
- PvE: bot -> bot -> bot -> bot -> boss -> next chapter.
- Real battle stones: no automatic regeneration.
- Server-authoritative PvE is used automatically inside Telegram WebApp when initData is available.
- Direct/browser testing falls back to the local PvE engine.
- XP uses TerritoryStore.addXp so level-up is real.
- PvE gives coins, XP and equipment loot.
- Boss has 3 phases.
- Daily/weekly quests remain available through the existing progression system.
- World/resource encounters enter the same PvE battle instead of resolving a fake local fight.
- Profile can use Telegram photo.
- Battle-stone counter is visible in the home combat controls.
- Arena is not loaded or linked by the new build.

Files in this patch replace/add the runtime layer of the current game-builde.
The old arena.js/arena.css files may remain physically in the repository, but the new index.html does not load or route to them.

Server API already present in territory-sdolars-server:
/api/pve/start
/api/pve/action
/api/pve/complete
/api/state
/api/player
/api/forge/upgrade
/api/forge/salvage
/api/reward/claim

No secrets are included in this patch.
