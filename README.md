# Territory — MERGED build

Это собранная мобильная версия Territory, объединяющая ключевые идеи двух веток:

- визуальная база старой Territory: `home-master.png` и `arena-night-approved.png`;
- механики Bolt: PvE-путь, боссы, уровни, экипировка, магазин, кузница, квесты, боевые камни и Arena 1×1;
- фиксированное меню из 5 кнопок — без горизонтального скролла и исчезновения кнопок;
- боевые камни НЕ регенерируют автоматически;
- камни выдаются за ежедневные задания и покупаются за кристаллы;
- Arena имеет локальный bot-fallback, чтобы кнопка боя не зависала при проблеме с сетью;
- Telegram WebApp имя и фото берутся из Telegram, если они доступны;
- ID/username не выводятся в верхней панели;
- стартовые тестовые данные нормализованы: уровень 1, VIP не подставляется;
- сохранение прогресса работает через localStorage.

## Запуск

Открой `index.html` через статический хостинг или GitHub Pages/Render.

## Сервер Arena

В `app.js` оставлен адрес текущего Worker:

`https://territory-sdolars-server.w0660077702.workers.dev`

Локальный bot-fallback работает независимо от него. Это специально сделано, чтобы на тесте Arena не могла заморозить игру из-за отсутствия ответа сервера.

## Что не переносилось

Старые экспериментальные файлы с десятками `territory-*-patch/fix/pass` не тащатся в этот чистый runtime. Это сделано намеренно: они больше не должны конкурировать друг с другом и менять DOM после загрузки игры.

## Важно

Фон и несколько боевых иллюстраций берутся из публичных GitHub-репозиториев проекта. При переносе в новый репозиторий их можно заменить на локальные файлы без изменения логики.
