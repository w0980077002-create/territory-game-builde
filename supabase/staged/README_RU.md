# Неприменённые серверные изменения TERRITORY

Эти файлы — **проект серверных миграций, не готовый для непосредственного применения на рабочей БД**:

- `territory_stage3_backend.sql`: защищённые таблицы/функции крафта, авторитетного кошелька, 25 камней/день и сезонных очков; флаги всех операций выключены. Не заменяет полный перенос сохранений.
- `territory_stage3_pvp_normalize.sql`: изменение сервера Арены для игроков и ботов; необходима отдельная тестовая проверка режимов 1x1 / 3x3 / Хаос.
- `territory_craft_catalog.json`: снимок 17 рецептов из действующего `src/game/professions.ts`. Тест `scripts/check-stage3.mjs` предупреждает о расхождении.

НЕ переносить эти SQL в migrations и НЕ применять в рабочем Supabase без резервной копии, отдельной проверки и подтверждения владельца. Особенно важно: существующий `players.game_state` остаётся клиентским, поэтому новая серверная инфраструктура сама по себе не закрывает накрутку.
