# Territory — перед использованием

Это архив исходников для отдельной тестовой ветки, а не подтверждённая production-сборка. Текущую опубликованную игру не заменяйте, пока не пройдены сборка и ручные игровые проверки.

## Что изменено
- Единый каталог экипировки магазина и базовых характеристик добычи с боссов.
- Предсказуемый рост характеристик в кузнице по слоту и редкости, без сложного начисления процентов на уже увеличенное значение.
- Единая формула при административном изменении уровня предмета.
- Миграция старых сохранений до версии 3; неизвестные пользовательские предметы сохраняются без догадок.
- Рабочие экраны и административную логику специально не переписывали.

## Проверки
- `npm run test:balance` — пройдено в рабочем окружении.
- Полная production-сборка и полный typecheck — НЕ подтверждены: установка зависимостей в рабочем окружении завершалась тайм-аутом.

## Перед запуском
1. Распаковать архив в отдельную ветку/тестовый проект, сохранив текущую рабочую версию.
2. Установить зависимости командой `npm ci`.
3. Настроить переменные окружения по `.env.example` в среде запуска; файл `.env` намеренно не включён в архив. Не публиковать секретные ключи.
4. Выполнить `npm run test:balance`, `npm run typecheck`, `npm run build`.
5. На тестовом аккаунте проверить магазин, кузницу, добычу с босса, миграцию старого сохранения, обычный бой, босса, арену и сохранение/повторную загрузку.

Сначала сделайте резервную копию сохранений/базы и проверьте миграцию на staging. Профессии и мастерство до 300-го уровня этим этапом ещё не реализованы — подготовлена основа для следующего этапа.
