# TERRITORY — действующий репозиторий

**Текущий рабочий проект:** TERRITORY, Telegram WebView, React/Vite/TypeScript + Supabase. Это НЕ архив ZIP и НЕ отдельная тестовая ветка. Рабочая ветка `main`; публикация в GitHub Pages подтверждается workflow и опубликованным SHA.

## Прежде чем менять игру

1. Читать [AGENTS.md](AGENTS.md) — единственные действующие правила владельца.
2. **Для Claude Code по Тёмной пещере:** сразу читать [CLAUDE.md](CLAUDE.md), раздел **«ЕДИНОЕ ИСПОЛНИТЕЛЬНОЕ ТЗ ДЛЯ CLAUDE CODE» в начале** [главного ТЗ Пещеры](docs/TERRITORY_DARK_CAVE_LOOTBORN_PRO_TZ_RU.md) и [журнал видеореференсов](docs/DARK_CAVE_REFERENCE_LOG_20261110_RU.md). **Не следовать общей очереди Codex** для этой задачи — это отдельное эксклюзивное поручение issue #314. Для прочих задач использовать [очередь Codex](docs/territory-v1-release/CODEX_QUEUE_RU.md) и [ТЗ исполнителей](docs/territory-v1-release/TZ_PACK_08_11_2026_RU.md); старые документы и PR — справочный материал.
3. Для новой механики: видимый игровой результат с настоящим артом → тест на телефоне → правки → только после принятия сложный серверный переход, если необходим.
4. Проверить изменённые файлы, `npm run typecheck`, `npm run build`, адресные тесты, затем успешную публикацию Pages. Не считать созданную задачу или зелёный QA новым игровым результатом.
5. Не менять сохранения, существующую экипировку, алмазы, VIP, награды, production Supabase, платежи и админку без отдельного разрешения и безопасного плана.

**Календарь действующих недель:** понедельник 00:00 UTC → следующий понедельник 00:00 UTC. Отдельный не запущенный чемпионат отключён.

**VIP:** только утверждённые плановые пороги $1 / $10 / $100 / $300 / $500 / $1000 / $3000 / $5000 / $8000 / $10000. Автопополнение пояса из своего инвентаря — VIP 3+, обычные игроки пополняют вручную.

**Экипировка:** при передаче/продаже сохраняются UUID, текущий фактический уровень, характеристики и история улучшений; следующий владелец может продолжить улучшение с текущего уровня, без сброса на начальный уровень. Никакие конкретные числа из примеров не задают игровой лимит. Не включать реальный аукцион без подтверждённой серверной передачи. Руны — 15 слотов на существующей серверной системе, не создавать дубль.

Технические исторические файлы миграций могут содержать более ранние правила. Не применять их поверх текущего сервера без проверки истории и разрешения.
