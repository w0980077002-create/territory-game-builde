TERRITORY — WORKING LOCAL BUILD 2026-10-03

This archive is a self-contained local client build assembled from the Territory home portrait package plus the current app.js and Arena engine available in the working source.

Open index.html or upload the folder contents to the GitHub Pages root.

Included:
- modular portrait Home with bundled image assets
- local navigation isolation
- inventory / shop / games / hero / quests / clan screens
- local PvE battle loop with battle-stone and energy spending
- Arena engine
- no CDN dependency

This is deliberately a clean build, not a patch archive.
